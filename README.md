# MySchedule 个人日程管理系统 (个人分支)

开发者：Tian Zhuoning
分支说明：本分支包含了 MySchedule 项目的完整独立实现，涵盖了底层核心逻辑、命令行/图形双界面以及语音扩展功能。

---

## 1. 核心功能亮点

* 安全的用户管理 (UserManager)
  - 支持多用户注册与登录。
  - 安全机制：拒绝明文存储，采用 Hash 算法对用户密码进行加密校验，保障数据安全。

* 高效的任务调度 (TaskManager)
  - 支持任务的增、删、改、查，以及按优先级和时间排序。
  - 持久化机制：采用“内存操作 + 实时覆写”策略，每次修改立即序列化到本地 .txt 文件，防止意外断电导致数据丢失。

* 跨语言语音交互 (Python 扩展)
  - 集成 Python 语音识别脚本，支持通过语音输入直接添加任务。
  - 架构设计：C++ 通过系统调用触发 Python 脚本，实现跨语言的高效协同。

* 双模式交互界面
  - CLI 命令行：轻量快捷，适合极客操作。
  - GUI 图形界面：基于 Qt 框架开发，提供直观友好的可视化操作面板。两者共用同一套底层代码。

---

## 2. 技术栈

- 核心语言：C++ 
- 图形框架：Qt
- 扩展脚本：Python 3
- 数据存储：本地格式化文本 (.txt)
